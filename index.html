TechFix ERP

Sistema de gestão especializada para assistência técnica de eletrônicos, integrando fluxo rigoroso de ordens de serviço baseado em Máquina de Estados Finita (FSM) e controle transacional de ponta a ponta.

Projetado para eliminar falhas operacionais, possui baixa atômica de estoque em transação ACID, controle de acesso baseado em papéis (RBAC) e emissão de laudos técnicos em PDF com assinatura.

TechFix ERP — Assistência Técnica

Desenvolvido para atender a rotina de manutenção de smartphones, notebooks, computadores e consoles. O núcleo do sistema é orientado por uma Máquina de Estados Finita (FSM) que impede saltos operacionais inválidos em ordens de serviço.

A separação de papéis (RBAC) garante isolamento entre técnicos, atendentes e administradores. A baixa de peças no estoque ocorre em transações atômicas seguras no PostgreSQL via Prisma, eliminando inconsistências de inventário.

Chaos Engineering & SRE

Projeto-laboratório de resiliência multi-região na AWS, com injeção controlada de falhas para estudar recuperação de serviços e métricas de RTO/RPO.

O laboratório explora um cenário Game Day de SRE: uma arquitetura de referência em duas regiões AWS (us-east-1 e us-west-2), com DynamoDB Global Tables e AWS Fault Injection Service (FIS) para exercitar cenários de falha e observar a recuperação.

  • Multi-Region Active-Active Tráfego distribuído via Route 53 com replicação bidirecional contínua
  • Injeção de Falhas (AWS FIS) Simulação controlada de partições de rede, indisponibilidade regional e latência extrema
  • RTO & RPO Métricas para avaliar tempo de recuperação e perda potencial de dados
  • Infraestrutura como Código Provisionamento 100% declarativo e reprodutível com Terraform (HCL)

Integração de Campo → ERP

Projeto demonstrativo de ingestão de dados operacionais para Oracle XE, com validação, fila de reprocessamento, Dead-Letter Queue e painel de conciliação.

PIPELINE SISTEMA DE CAMPO → ORACLE ERP

Dead-Letter Queue · Contratos de Dados · Painel de Auditoria & Conciliação

Ver Repositório no GitHub →

O projeto simula um cenário real da agroindústria: a coleta de apontamentos operacionais (pesagem de colheita, horímetro de máquinas e consumo de insumos) em condições de conectividade instável de campo.

Os dados passam por validação estrita de contrato de schema antes de persistir no Oracle Database XE. Falhas transitórias são isoladas em uma Dead-Letter Queue (DLQ) com retentativas automáticas, e um painel analítico de conciliação monitora discrepâncias operacionais em tempo real.

Finnace_Tech · BaaS & Crédito

Projeto demonstrativo de serviços financeiros e operações de crédito, simulando componentes de um fluxo Banking-as-a-Service.

Composto por quatro módulos em ambiente de demonstração: Simulador Pix BaaS, Motor de Decisão e Risco de Crédito, Plataforma White-Label Multi-Tenant e esteira de infraestrutura automatizada com Terraform (IaC).

# Motor de Decisão de Risco de Crédito & Score Dinâmico
from dataclasses import dataclass
from decimal import Decimal

@dataclass
class PropostaCredito:
    proponente_id: str
    renda_mensal: Decimal
    score_bureaux: int
    valor_solicitado: Decimal
    comprometimento_renda: Decimal

def avaliar_risco(proposta: PropostaCredito) -> dict:
    # Regra prudencial: limite máximo de 30% de comprometimento de renda
    limite_aprovado = proposta.renda_mensal * Decimal("0.30")
    taxa_risco = Decimal("0.025") if proposta.score_bureaux >= 750 else Decimal("0.045")
    aprovado = (proposta.score_bureaux >= 600) and (proposta.comprometimento_renda < Decimal("0.35"))
    
    return {
        "aprovado": aprovado,
        "limite_concedido": min(proposta.valor_solicitado, limite_aprovado),
        "taxa_mensal": taxa_risco,
        "status": "APROVADO_AUTOMATICO" if aprovado else "ENCAMINHADO_MESA"
    }
  • Simulador BaaS Pix: Liquidação de pagamentos instantâneos com regras do BACEN
  • Motor de Análise de Risco: Avaliação paramétrica de score, renda e taxa de juros personalizada
  • White-Label Multi-Tenant: Isolamento criptográfico e de dados entre múltiplos parceiros comerciais
  • Infraestrutura como Código (IaC): Provisionamento automatizado de ambientes com Terraform
  • Testes automatizados cobrindo cenários unitários e fluxos de integração ponta a ponta
